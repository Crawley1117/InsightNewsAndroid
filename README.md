# InsightNews for Android

## 更新日志

### 最新版本：0.1.5.8 (Token 管理与登录流程优化)

#### 🔐 认证系统核心改进
- **Token 存储与管理**：实现了对服务器返回认证 Token 的安全存储和读取，增强了应用的安全性。
- **登录/注册流程优化**：
  - **LoginActivity**: 登录成功后，服务器返回的 Token 现在会被正确保存到 `AuthRepository`。
  - **RegisterActivity**: 注册成功后，服务器返回的 Token 现在会被正确保存到 `AuthRepository`。
  - **AuthRepository**: 新增 `setLoggedIn(String userId, String token)` 和 `getAuthToken()` 方法，用于管理 Token。
- **调试模式调整**：
  - **LoginActivity**: 移除了验证码调试模式 (`041122`)。
  - **LoginActivity**: 新增密码调试模式，输入密码 `1117` 即可登录成功。
- **代码清理**：移除了硬编码的 Token 和大量冗余注释，使代码更清晰、安全。
